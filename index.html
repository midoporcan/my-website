20 / 21
FTP
File Transfer Protocol
TCPFile Transfer
Port 20 carries data; port 21 handles control commands. Used for transferring files between client and server.
22
SSH
Secure Shell
TCPRemote Access
Encrypted remote login and command execution. Replaced Telnet as the standard for secure remote administration.
23
Telnet
Terminal Network
TCPRemote Access
Unencrypted remote terminal access. Considered insecure and largely replaced by SSH; still used on legacy devices.
25
SMTP
Simple Mail Transfer Protocol
TCPMail
Core protocol for sending email between mail servers. Used by mail clients to submit outgoing mail to a relay server.
53
DNS
Domain Name System
TCP / UDPDNS
Resolves domain names to IP addresses. UDP for standard queries; TCP for large responses and zone transfers.
67 / 68
DHCP
Dynamic Host Config Protocol
UDPNetwork
67 is server; 68 is client. Automatically assigns IP addresses, gateways, and DNS servers to network devices.
69
TFTP
Trivial File Transfer Protocol
UDPFile Transfer
Simple file transfer with no authentication. Used for PXE booting and uploading firmware to network devices.
80
HTTP
HyperText Transfer Protocol
TCPWeb
Foundation of data communication on the web. Browsers use it to request and receive web pages from servers.
110
POP3
Post Office Protocol v3
TCPMail
Downloads email from server to local client and typically deletes it from the server. Single-device email retrieval.
119
NNTP
Network News Transfer Protocol
TCPNetwork
Used for reading and posting Usenet news articles. Transfers messages between servers and reader clients.
123
NTP
Network Time Protocol
UDPNetwork
Synchronizes clocks of computers over a network. Critical for security, logging, and distributed systems.
143
IMAP
Internet Message Access Protocol
TCPMail
Retrieves email while keeping messages on the server, enabling multi-device access with folder and flag support.
161 / 162
SNMP
Simple Network Management Protocol
UDPNetwork
161 polls managed devices; 162 receives traps (alerts). Monitors routers, switches, and servers.
389
LDAP
Lightweight Directory Access Protocol
TCP / UDPNetwork
Accesses distributed directory services. Used for centralized authentication (Active Directory) and user management.
443
HTTPS
HTTP over TLS/SSL
TCPWeb
Encrypted web traffic using TLS. Standard for all secure websites; protects data between browsers and servers.
445
SMB
Server Message Block
TCPFile Transfer
Windows file and printer sharing. Enables reading and writing files on a remote server; used in NAS and Active Directory.
465
SMTPS
SMTP over SSL
TCPMail
Encrypted SMTP using implicit TLS from the start of the connection. Used for secure email submission.
514
Syslog
System Logging Protocol
UDPNetwork
Sends system event logs to a central log server. Used for monitoring, auditing, and troubleshooting.
587
SMTP Submission
Mail Submission Agent
TCPMail
Modern standard for sending email from clients. Requires authentication and uses STARTTLS. Preferred over port 25.
636
LDAPS
LDAP over SSL
TCPSecurity
Secure LDAP with TLS encryption. Used for encrypted directory queries and authentication in enterprise environments.
853
DNS over TLS
DoT
TCPSecurity
Encrypts DNS queries using TLS to prevent eavesdropping. Improves privacy over standard DNS on port 53.
993
IMAPS
IMAP over SSL
TCPMail
Encrypted IMAP using TLS. Secure email access keeping messages on the server and synced across multiple devices.
995
POP3S
POP3 over SSL
TCPMail
Secure POP3 with TLS encryption. Protects credentials and email content during retrieval from mail servers.
3306
MySQL
MySQL / MariaDB
TCPDatabase
Default port for MySQL and MariaDB connections. Applications connect here to execute queries and manage data.
5432
PostgreSQL
Postgres Database
TCPDatabase
Default port for PostgreSQL connections. Used by applications, ORMs, and tools to connect to Postgres instances.
